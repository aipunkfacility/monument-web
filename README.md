# Monument Web

Сайт и email-шаблон для сервиса профессиональной ретуши фотографий для гравировки на памятниках.

## О проекте

Проект включает:
- **Веб-сайт** — лендинг с описанием услуг, галереей работ и ценами
- **Email-шаблон** — готовый шаблон для рассылки мастерам по изготовлению памятников

## Структура проекта

```
monument-web/
├── index.html              # Основной сайт (лендинг)
├── css/
│   └── style.css           # Стили (glassmorphism + темы)
├── img/
│   ├── male.jpg            # Пример ретуши (мужской портрет)
│   └── female.jpg          # Пример ретуши (женский портрет)
├── email/
│   └── email.html          # Email-шаблон для рассылки
├── AGENTS.md               # Руководство для AI-агентов
└── pricing-section-prompt.txt  # Исходный промпт для секции цен
```

## Запуск

### Веб-сайт

Откройте `index.html` в браузере или используйте локальный сервер:

```bash
python -m http.server 8000
# Откройте http://localhost:8000
```

### Email-шаблон

Откройте `email/email.html` в браузере для предпросмотра. Для отправки используйте любой email-сервис (SendGrid, Mailchimp и т.д.).

## Дизайн

### Веб-сайт

- **Стиль:** Glassmorphism (тёмный фон, стеклянные карточки)
- **Темы:** Тёмная и светлая с переключателем
- **Адаптивность:** Мобильные устройства (320px+)
- **Иконки:** Remix Icon v4.2.0

### Email-шаблон

- **Вёрстка:** Табличная (для совместимости с email клиентами)
- **Стили:** Инлайновые (Outlook, Gmail)
- **Ширина:** 600px (стандарт для email)
- **Изображения:** Внешний CDN (memorial-img.netlify.app)
